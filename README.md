# Warehouse Lease Landing Page

A premium B2B industrial property leasing landing page for a newly built factory complex in Bac Ninh, Vietnam.

## Project overview

This project is a static marketing website designed for international industrial buyers and leasing inquiries. It includes:

- premium industrial branding and layout
- multilingual support for Vietnamese, English, Japanese, Korean, and Chinese
- project overview and facility highlights
- embedded map location for the property
- inquiry form and direct contact actions

## Files

- `index.html` — page structure and content
- `styles.css` — visual design and responsive layout
- `script.js` — multilingual handling, animations, and form behavior
- `1/` — property images used on the landing page

## Local preview

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Deployment

This project is designed for static hosting and can be deployed to any static web host or CDN.

## Contact

For leasing inquiries, use the contact details provided on the page or reach out through the direct inquiry options.
